# How to Create a Shortcut for https://cursor.com/agents on Brave Browser (Android)

## Method 1: Standard Approach (Add to Home Screen)

1. **Open Brave Browser** on your Android device
2. **Navigate to** https://cursor.com/agents
3. **Tap the three dots menu** (⋮) in the top-right corner
4. **Select "Add to home screen"**
5. **Choose your preference:**
   - If you see two options, choose "Create shortcut" (not "Install app")
   - If only one option appears, it will create a shortcut
6. **Customize the name** if desired
7. **Tap "Add"** to create the shortcut

## Method 2: Workaround for Simple Shortcuts (Recommended)

This method ensures you get a simple bookmark shortcut instead of a web app:

1. **Open Brave Browser** and go to https://cursor.com/agents
2. **Turn on airplane mode** (disable internet connection)
3. **Reload the page** to ensure you see a "No Internet" message
4. **Tap the three dots menu** (⋮) and select "Add to home screen"
5. **Name your shortcut** and tap "Add"
6. **Turn off airplane mode** to restore internet connection

This workaround creates a simple bookmark shortcut that opens the exact URL in your browser.

## Important Considerations

### Known Issues with Brave Shortcuts on Android:
- **Shortcuts may disappear** after phone restarts or updates
- This is a known bug affecting many Brave users on Android
- Chrome shortcuts typically don't have this issue

### Alternative Solutions:

#### Option A: Use Chrome for This Shortcut
- Create the shortcut using Chrome browser instead
- Chrome shortcuts are more stable and don't disappear after restarts

#### Option B: Use Hermit App
- Install the "Hermit — Lite Apps Browser" from Google Play Store
- This app provides more reliable shortcuts and additional customization options
- Better long-term solution if you plan to create multiple website shortcuts

#### Option C: Create a Bookmark
- Instead of a home screen shortcut, create a bookmark in Brave
- Access it quickly from the bookmarks menu
- More reliable than shortcuts but requires an extra step to access

## Troubleshooting

### If Your Shortcut Disappears:
1. **Check if it's in a different location** on your home screen
2. **Recreate the shortcut** using the methods above
3. **Consider using the Hermit app** for more reliable shortcuts
4. **Use Chrome browser** as an alternative for important shortcuts

### If the Shortcut Opens the Wrong Page:
- Use Method 2 (airplane mode workaround) to ensure it opens the exact URL
- This prevents the shortcut from opening a generic start page

## Summary

While Brave browser allows you to create shortcuts to websites, there are known stability issues on Android. For the most reliable experience with https://cursor.com/agents, consider using Chrome browser or the Hermit app for creating your shortcut. The airplane mode workaround (Method 2) provides the best results when using Brave.
